== Composants embarqués et exécutés par Aria ==

Vaultwarden
  Serveur compatible Bitwarden, compilé depuis le source officiel sans
  aucune modification. La version et le commit exacts figurent dans
  BUILDINFO.txt et dans les notes de chaque release.
  Licence  : GNU Affero General Public License v3.0 (AGPL-3.0)
  Source   : https://github.com/dani-garcia/vaultwarden
  Texte    : LICENCE-Vaultwarden-AGPL-3.0.txt (dans le zip de la release)

Interface web (web vault)
  Version open source des clients Bitwarden, compilée par le projet
  bw_web_builds ; téléchargée depuis ses releases officielles et vérifiée
  par SHA-256.
  Licence  : GNU General Public License v3.0 (GPL-3.0)
  Source   : https://github.com/dani-garcia/bw_web_builds
             https://github.com/bitwarden/clients
  Texte    : LICENCE-interface-web-GPL-3.0.txt (dans le zip de la release)
